# Ani — 2:00 demo script

Vertical or 16:9 screen recording. Record the browser at 1440×900, zoom the
studio to ~110%. Keep the cursor deliberate. Have **Wispr Flow armed** before
recording.

| Time | Picture | Say |
|---|---|---|
| 0:00–0:10 | Hero at rest. The puffy ANI, the pinned residents. | “Every brand wants a mascot that feels alive. Today that means a canned move library, a rigged file, or a video model.” |
| 0:10–0:22 | Scroll to the prompt. Cursor in the input. | “We built Ani. You describe the character and the feeling — and it invents both the mascot and the performance, in code.” |
| 0:22–0:40 | **Hold Fn + Space.** Dictate with Wispr Flow: *“A mischievous fox named Juno for a fintech startup. Sharp, quick, points at the chart and winks.”* Press Generate. | “No forms. I’m just talking. Wispr Flow turns the thought into a brief; the director turns the brief into a genome and a score.” |
| 0:40–0:58 | Studio loads Juno. Let the loop play through the point/wink. Point at the stage, then the timeline. | “Meet Juno. Original vector geometry — not a template. And this timeline is not a clip library: these are beats, written for this fox, then layered with breath, weight and follow-through.” |
| 0:58–1:10 | Click `SCORE`. Show the JSON. Click `GENOME`. | “The whole character is data. Here is the score; here is the genome. Every frame is one pure function of one clock.” |
| 1:10–1:25 | Back to stage. Click suggestion chips: **More playful**, **Add a scarf**, **Make it wave**. Let the character change. | “This is the no-code part. You talk to it. More playful. Add a scarf. Make it wave. Same genome, recompiled performance.” |
| 1:25–1:43 | Upload the reference image. Show the palette message. Then upload the logo in Brand. | “I can also drop a reference. Ani reads its palette, chroma and temperature in the browser, then builds an original interpretation — never a trace. Drop the logo and it lands on the chest, still vector.” |
| 1:43–1:54 | Click the SVG download. Open the downloaded file (or show file size). | “Export is a real SVG — about 10KB. Transparent, crisp, editable. No video model, no server, no key.” |
| 1:54–2:00 | Cut to the repo / “make it alive.” footer. | “Ani. Type a feeling. Meet a character that moves like it means it.” |

## Prep checklist

- [ ] `pnpm dev` running, browser at 1440, page scrolled to top, no dev overlay.
- [ ] Wispr Flow enabled and tested in the prompt field.
- [ ] Reference image on the desktop (a colorful product shot or mascot).
- [ ] Logo PNG on the desktop.
- [ ] Close other tabs and notifications.
- [ ] Record 2:00 max; do a silent rehearsal first.

## Backup line if the live generation stalls

“The director runs locally — no network, no key — so this is the same result every time.”
Then click **Remix** to show a second, different performance from the same brief.
